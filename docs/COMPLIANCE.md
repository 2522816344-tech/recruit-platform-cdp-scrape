# Compliance

本文件是项目合规性边界声明。**使用本工具前请仔细阅读。**

## 用途边界

### ✅ 允许的用途

- **个人使用**：用你自己已登录的浏览器会话，抓取公开可见的招聘信息做个人调研
- **本地分析**：抓取结果保存在本地，仅供你个人分析、报告、决策使用
- **学术研究**：在符合学术伦理的范围内用于非商业研究项目

### ❌ 不允许的用途

- **任何商业用途**：禁止把抓取结果用于商业产品、商业报告、客户交付、二次销售
- **绕过风控**：禁止修改本项目代码用于绕过人机验证、短信验证、滑块验证
- **批量账号**：禁止用多个账号绕过平台限制
- **传播数据**：禁止把抓取数据上传到云端、销售、分享给他人（除非是公开可见的部分）
- **抓取受版权保护数据库**：LinkedIn / Glassdoor / Indeed 等海外招聘平台的 PR 不被接受
- **伪造身份**：禁止假装是某个公司 / 招聘方去抓数据

## ToS / 合规风险

招聘平台的服务条款（ToS）通常会禁止自动化访问。本项目通过**复用你已登录的浏览器会话**
来规避大部分风控，但仍存在以下风险：

| 风险 | 缓解 |
|---|---|
| 平台 ToS 禁止爬虫 | 用户自负其责；项目不强制用户接受 ToS |
| 风控拦截（验证码 / 限频） | 检测到立即暂停，**不实现自动化绕过** |
| 账号被封 | 不批量模拟账号；每个公司名单都是人工整理 |
| 数据准确性 | 多平台交叉验证 + 人工复核剔除 |
| 个人隐私 | 公司名单通常是公开信息；员工姓名等隐私字段**不抓** |
| IP 风险 | 默认直连；如必要可走 `CHROME_PROXY` 代理 |

## 法律边界

### 中国大陆

- 《数据安全法》：禁止非法获取重要数据 / 大量数据 / 关键信息基础设施数据
- 《个人信息保护法》：禁止非法获取 / 出售个人信息
- 《网络安全法》：禁止非法侵入他人网络 / 干扰正常功能

本项目：
- 不抓取个人信息（员工姓名、电话、邮箱等）
- 不抓取受保护的商业秘密
- 不发起高频请求（`pace` 节流）
- 不储存数据 / 不传输数据

### 欧盟

- 《GDPR》：所有数据来自用户本人的合法账号，由用户自行决定如何存储 / 处理

### 美国

- 各地反爬判例不同（如 hiQ v. LinkedIn）；本项目只针对公开可见、用户已登录后可见的数据

使用本工具时，你**必须**同意：

1. 你只使用**你自己的账号**和**你自己已登录的浏览器会话**

3. 你不会尝试绕过任何平台的风控 / 验证码
4. 你接受：使用本工具可能违反某些平台的 ToS，导致账号被封等后果由你自行承担
